### Шаг 2: Загрузка на PHP хостинг

#### Вариант A: Через FTP/SFTP (FileZilla, WinSCP)

1. **Подключитесь к хостингу** через FTP клиент:
   - Host: ваш_хостинг.com
   - Username: ваш_логин
   - Password: ваш_пароль
   - Port: 21 (FTP) или 22 (SFTP)

2. **Перейдите в корневую папку**:
   - Обычно это `public_html/` или `www/` или `htdocs/`

3. **Загрузите ВСЕ файлы** из `frontend/out/`:
   - Выделите все файлы и папки в `frontend/out/`
   - Перетащите их в корневую папку на сервере
   - Убедитесь, что `.htaccess` также загружен

4. **Проверка структуры** на сервере:
   ```
   public_html/
   ├── .htaccess            ← ВАЖНО!
   ├── index.html
   ├── narratives.html
   ├── _next/
   │   └── static/
   └── narratives/
       ├── tokaev-image.html
       └── ...
   ```

#### Вариант B: Через SSH (если доступен)

```bash
# На вашем Mac/Linux компьютере
cd /Users/max/telethon-bot/sgeo/frontend

# Загрузка через scp
scp -r out/* username@your-server.com:/path/to/public_html/

# Или через rsync (быстрее)
rsync -avz --progress out/ username@your-server.com:/path/to/public_html/
```

#### Вариант C: Через cPanel File Manager

1. Войдите в **cPanel**
2. Откройте **File Manager**
3. Перейдите в `public_html/`
4. Нажмите **Upload**
5. Загрузите все файлы из `frontend/out/`
6. Убедитесь, что `.htaccess` загружен

## 🔧 Возможные проблемы и решения

### Проблема 1: 404 ошибка на подстраницах

**Симптом:** Главная страница открывается, но `/narratives` или другие страницы дают 404

**Решение:**

1. **Проверьте .htaccess:**
   ```bash
   # Убедитесь, что файл загружен
   ls -la /path/to/public_html/.htaccess
   ```

2. **Проверьте права доступа:**
   ```bash
   chmod 644 .htaccess
   ```

3. **Включите mod_rewrite на хостинге:**
   - В cPanel: Apache Handlers → включить mod_rewrite
   - Или свяжитесь с техподдержкой хостинга

4. **Альтернативный .htaccess** (если не работает):
   ```apache
   <IfModule mod_rewrite.c>
     RewriteEngine On
     RewriteBase /
     RewriteRule ^index\.html$ - [L]
     RewriteCond %{REQUEST_FILENAME} !-f
     RewriteCond %{REQUEST_FILENAME} !-d
     RewriteCond %{REQUEST_FILENAME} !-l
     RewriteRule . /index.html [L]
   </IfModule>
   ```

### Проблема 2: Медленная загрузка

**Решение:**

1. **Включите сжатие gzip** (уже настроено в .htaccess)
2. **Проверьте кэширование браузера**
3. **Используйте CDN** (например, Cloudflare)

### Проблема 3: Белый экран или ошибки JavaScript

**Решение:**

1. **Откройте консоль браузера** (F12 → Console)
2. **Проверьте пути к файлам:**
   - Убедитесь, что папка `_next/` загружена
   - Проверьте права доступа: `chmod -R 755 _next/`

3. **Очистите кэш браузера**: Ctrl+Shift+R (Windows) или Cmd+Shift+R (Mac)

### Проблема 4: Графики Recharts не отображаются

**Причина:** Это нормально для статического экспорта. Графики рендерятся на клиенте.

**Проверка:** Подождите 2-3 секунды после загрузки страницы.

## 🆘 Техническая поддержка

### Если что-то не работает:

1. **Проверьте логи сервера:**
   - В cPanel: Metrics → Errors
   - Или: `tail -f /path/to/error.log`

2. **Проверьте консоль браузера:**
   - F12 → Console (ищите ошибки красным)
   - Network (проверьте 404 запросы)

3. **Свяжитесь с техподдержкой хостинга:**
   - Убедитесь, что mod_rewrite включен
   - Проверьте права доступа к файлам

4. **Создайте issue в репозитории:**
   - Опишите проблему
   - Приложите скриншоты консоли
   - Укажите хостинг и домен
